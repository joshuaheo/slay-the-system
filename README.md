# 🎮 slay-the-system

> 2026년 1학기 시스템프로그래밍 팀프로젝트

## 프로젝트 소개

**slay-the-system**은 C 언어와 ncurses 라이브러리를 이용하여 구현한 터미널 기반 카드 로그라이크 게임입니다.

플레이어는 다양한 카드를 활용하여 적과 전투를 진행하고, 전투를 통해 획득한 카드와 유물로 덱을 강화하며 최종 보스를 처치하는 것을 목표로 합니다.

게임은 총 15층으로 구성되어 있으며, 전투, 이벤트, 상점, 휴식, 보물방 등 다양한 스테이지를 탐험할 수 있습니다.

## 게임 진행 방식

플레이어는 15층으로 구성된 맵을 탐험하며 다양한 스테이지를 선택하게 됩니다.

일반 전투와 정예 전투를 통해 카드와 유물을 획득할 수 있으며, 이벤트와 상점을 활용하여 덱을 강화할 수 있습니다.

최종적으로 15층의 보스를 처치하면 게임이 클리어됩니다.

게임은 총 15층으로 구성되어 있으며, 일부 층에서는 두 가지 스테이지 중 하나를 선택할 수 있습니다.

| 5 | 일반 전투 / 이벤트 |
| 6 | 일반 전투 / 휴식 |
| 7 | 정예 전투 / 이벤트 |
| 8 | 일반 전투 |
| 9 | 보물방 |
| 10 | 상점 / 일반 전투 |
| 11 | 일반 전투 / 휴식 |
| 12 | 정예 전투 / 일반 전투 |
| 13 | 일반 전투 |
| 14 | 휴식 |
| 15 | 최종 보스 |

## 주요 기능

### ⚔️ 카드 기반 전투

* 랜덤한 조합으로 출현하는 적 조합
* 턴제 카드 전투 시스템
* 다중 적 전투 지원
* 적 행동 패턴 시스템
* 방어도, 취약, 힘 버프등으로 인한 시너지

### 🃏 덱 빌딩

* 카드 획득 및 제거
* 취약,소멸, 힘, 방어도 공격횟수등 다양한 메커니즘
* 카드 희귀도 시스템
* 모든 카드 소멸 후 공격, 매 턴 에너지 획득 등 특수 메커니즘 카드 구현

### 🏺 유물 시스템

* 유물 희귀도 시스템
* 전투 시작 시, 턴 시작 시 등 여러 시점에 발동하는 유물 

### 🏪 다양한 스테이지

* 일반 전투
* 정예 전투
* 보스 전투
* 이벤트
* 상점
* 휴식
* 보물방

### 💾 저장 시스템

* 계정 생성 및 로그인
* 다중 세이브 슬롯 지원
* 자동 저장 기능
* 이어하기 기능
* 슬롯 별 플레이 시간 저장

## 시스템 프로그래밍 요소

본 프로젝트는 시스템프로그래밍 과목에서 학습한 개념을 활용하여 구현되었습니다.

### 파일 시스템 활용

* 저장 시스템에서는 `open()`, `read()`, `write()`, `fsync()`, `close()`, `unlink()`, `stat()` 등의 파일 시스템 관련 함수를 사용하여 세이브 파일 저장, 불러오기, 삭제, 마지막 저장 시간 표시 기능을 구현하였다.
* 계정별 세이브 파일 생성
* 게임 진행 상태 저장 및 불러오기
* 세이브 파일 삭제를 통한 데이터 관리

### 시그널 처리

* SIGINT(Ctrl+C) 시그널 처리
* 전투 중 안전 종료 기능 구현

### 터미널 기반 UI

* ncurses 라이브러리를 이용한 인터페이스 구현
* 키보드 입력 처리
* 카드 적용에 따른 적 체력 및 에너지 실시간 반영 구현
